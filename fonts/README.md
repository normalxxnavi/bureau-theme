# Fonts

Open-source fonts bundled with the extension (optional; installed only if the user picks a typography or turns on the Bureau terminal).

| Set | Font | Use | License |
|---|---|---|---|
| **Bureau terminal** | Bureau Prompt Icons (`prompt/BureauPromptIcons.ttf`) | Icons of the terminal prompt, behind the terminal font | Original, MIT (same as the extension) |
| **Bureau** (*Control*) | Overpass Mono | Editor, terminal, debug console, code in chat | SIL OFL 1.1 — `bureau/OFL-Overpass.txt` |
| **Bureau** (*Control*) | Overpass | Chat and Markdown preview | SIL OFL 1.1 — `bureau/OFL-Overpass.txt` |
| **Resonant** (*Control Resonant*) | Space Mono | Editor, terminal, debug console, code in chat | SIL OFL 1.1 — `resonant/OFL-SpaceMono.txt` |
| **Resonant** (*Control Resonant*) | Space Grotesk | Chat and Markdown preview | SIL OFL 1.1 — `resonant/OFL-SpaceGrotesk.txt` |

Why these fonts: *Control* uses commercial typefaces (Interstate for signage and UI, ITC Avant Garde Gothic for titles, Akzidenz-Grotesk for documents), which cannot be redistributed. **Overpass** is an open-source font derived from *Highway Gothic*, the same road-sign lettering Interstate is based on. The fonts of *Control Resonant* are not publicly documented; **Space Mono / Space Grotesk** were chosen for their geometric, retro-futuristic look.

If you own **Interstate Mono** / **Interstate**, the Bureau set uses them first.

Sources: [google/fonts](https://github.com/google/fonts) (`ofl/overpassmono`, `ofl/overpass`, `ofl/spacemono`, `ofl/spacegrotesk`). The `.ttf` files are unmodified; only renamed.

**Bureau Prompt Icons** is generated by `scripts/prompt-icons.js` (`npm run prompt-icons`) from the same 16 × 16 drawings as Bureau Product Icons, plus the system icons of the Bureau terminal. Its glyphs use Unicode private-use code points outside the Nerd Fonts ranges (U+E1B0–U+E1BF), so it can sit behind any terminal font, Nerd Fonts included.
